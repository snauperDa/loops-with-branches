## Описание
Программа на языке C++ демонстрирует использование циклов и операторов ветвления при расчёте электротехнической величины.

Для четырёх различных комбинаций параметров цепи R, L, C вычисляется значение тока i в зависимости от времени t и постоянного напряжения E. При этом в зависимости от знака параметра Beta выбирается одна из формул расчёта: при Beta > 0 используется тригонометрическая функция sin, при Beta ≤ 0 — гиперболическая функция sinh.

## Теоретические формулы

Промежуточные величины вычисляются по следующим формулам:

$$
\gamma = \frac{R}{2L}
$$

$$
\beta = \frac{10^6}{L C} - \gamma^2
$$

$$
\alpha = \frac{10^3 \cdot E \cdot e^{-\gamma t}}{L}
$$

Значение тока $i$:

$$
i = \begin{cases}
\frac{\alpha \cdot \sin(\sqrt{\beta}\, t)}{\sqrt{\beta}}, & \beta > 0,\\[6pt]
\frac{\alpha \cdot \sinh\!\left(\sqrt{-\beta}\, t\right)}{\sqrt{-\beta}}, & \beta \le 0.
\end{cases}
$$

## Входные данные
Программа запрашивает у пользователя два значения:

- `E` — постоянное напряжение (В)
- `t` — время (с)

## Выходные данные
Для каждого из четырёх наборов параметров (R, L, C) на экран выводится строка:

```
Beta = <значение β> i = <значение i>
```

Наборы параметров, используемые в расчётах:

| Номер | C (Ф) | L (Гн) | R (Ом) |
|---|------|--------|--------|
| 1 | 0.03 | 0.6    | 5000   |
| 2 | 0.03 | 6.0    | 10000  |
| 3 | 0.3  | 0.6    | 5000   |
| 4 | 0.3  | 6.0    | 10000  |

## Алгоритм работы
1. Ввести значения E и t.
2. В цикле `for` по `number` от 1 до 4 выбрать соответствующий набор (C, L, R) с помощью оператора `switch`.
3. Рассчитать `γ`, `β`, `α`.
4. В зависимости от знака `β` вычислить ток `i` (по формуле с `sin` или `sinh`).
5. Вывести значения `β` и `i` для каждого случая.
6. Завершить программу.
